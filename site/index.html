costgate

Monthly AWS cost projection of a terraform plan (or tofu plan), before vs. after per resource, with a pull request gate. Single Go binary, offline, no AWS credential, no SaaS.

What it does

  • Shows the monthly cost before vs. after for each resource in the plan.
  • Gates the pull request by exit code: a distinct code when the delta exceeds a ceiling or a resource has no known price.
  • Fail-closed: a created or changed resource it cannot price fails the check (exit 2). No unknown resource silently becomes US$ 0.
  • Runs offline with no AWS credential: prices come from a versioned snapshot of the public AWS Price List Bulk API, embedded in the binary.
  • Each cost line carries the keys of the AWS bill (SKU, usage type, rate code, invoice description), so it can be matched against the Cost and Usage Report.

Install

Homebrew (macOS and Linux):

brew install leosavio/tap/costgate

Homebrew 7.0.11 and later refuse formulae from non-official taps until you trust them. If brew install stops with "Refusing to load formula ... from untrusted tap", run this and install again:

brew trust --formula leosavio/tap/costgate

Go toolchain:

go install github.com/leosavio/costgate/cmd/costgate@latest

Or download a signed release archive (darwin/linux, arm64/amd64) and verify its checksum and keyless signature.

Quick start

terraform show -json tfplan > plan.json
costgate diff --plan plan.json --max-monthly-delta 10

Exit 0: everything priced and within the ceiling. Exit 1: above the ceiling. Exit 2: a created or changed resource has no known price. Exit 3: usage or input error.

How it works

A weekly workflow turns the public AWS Price List into a versioned snapshot that ships inside the binary. costgate diff reads only the plan JSON, an optional usage premises file and that snapshot: no account, no network, no clock.

costgate and Infracost

Both read a Terraform or OpenTofu plan and comment the monthly cost on the pull request. Infracost covers AWS, Azure and Google and queries its pricing API with an Infracost login; costgate covers AWS only, runs with no account and no network, and fails the check on any resource it cannot price.
